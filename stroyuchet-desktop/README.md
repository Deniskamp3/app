# СтройУчёт - Локальное десктоп-приложение для учёта продаж строительных материалов

## Версия 1.0 | Дата: 25.05.2026

### Описание
Автономное настольное приложение для предприятий торговли стройматериалами, работающее на Windows без установки дополнительного ПО.

### Требования к системе
- **ОС**: Windows 7 SP1 / 8 / 8.1 / 10 / 11
- **Процессор**: Intel/AMD 1.5 ГГц, 2 ядра
- **ОЗУ**: 2 ГБ (рекомендуется 4 ГБ)
- **Место на диске**: 300 МБ

### Установка
```bash
# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### Запуск в режиме разработки
```bash
python src/main.py
```

### Сборка в EXE
```bash
build_scripts\build_exe.bat
```
